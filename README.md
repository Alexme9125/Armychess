# 陆军棋

双人陆战棋：液态玻璃棋盘、云母棋子、布阵蓝图码、人机三种人格，以及房间码 PVP（含旁观）。

## 运行

```bash
npm install
npm test          # 规则引擎
npm run dev       # 开发：Vite :5173 + 服务 :3000
npm start         # 构建前端并由 Node 托管（默认 :3000）
```

浏览器打开 `http://localhost:5173`（开发）或 `http://localhost:3000`（生产）。

## 流程

1. 在**布阵工作室**拖拽 25 枚棋子，保存得到 6 位蓝图码。
2. **人机**：输入蓝图码，选择谨慎 / 平衡 / 激进人格。
3. **PVP**：创建房间得到房间码；双方读取蓝图码并准备后开局。座位满后再进入为旁观；非对弈期可站起 / 坐下。对弈中有人离开则对局结束。

房主可在开局前选择明棋或暗棋。黑方先行。

## 彩蛋（仅人机）

- `325799` 雷霆模式：除军旗外全是司令。
- `350234` 炸弹兵模式：前五排可布点全是炸弹，底排三工兵加大本营军旗与司令。
